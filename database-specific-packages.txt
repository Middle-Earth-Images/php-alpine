| Package                    | Database                               | Notes                                                                                                                                                            |
| -------------------------- | -------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `php85-pdo`                | All (PDO-based connections)            | Provides the **core PDO API**. Required if you want to connect to any database using PDO. Must be installed alongside a specific PDO driver to actually connect. |
| `php85-mysqli`             | MySQL / MariaDB                        | MySQL-specific extension for procedural and object-oriented access. Not needed if using PDO with `php85-pdo_mysql`.                                              |
| `php85-pdo_mysql`          | MySQL / MariaDB                        | PDO driver for MySQL / MariaDB. Works **with `php85-pdo`** to enable PDO connections.                                                                            |
| `php85-pdo_pgsql`          | PostgreSQL                             | PDO driver for PostgreSQL. Works with `php85-pdo`. Not currently in your Dockerfile but commonly added for Postgres support.                                     |
| `php85-pdo_dblib`          | SQL Server / Sybase                    | PDO driver for FreeTDS / SQL Server / Sybase connections. Requires `freetds-dev` to compile.                                                                     |
| `php85-sqlsrv`             | SQL Server                             | PECL extension for SQL Server, requires FreeTDS or Microsoft drivers.                                                                                            |
| `php85-oci8`               | Oracle                                 | PDO/OCI driver for Oracle connections, requires Oracle Instant Client.                                                                                           |
| `freetds-dev`              | SQL Server / Sybase                    | Build-time headers for compiling `pdo_dblib` or `sqlsrv` extensions. Not needed at runtime if driver is precompiled.                                             |
| `libaio`                   | Oracle / async DB drivers              | Needed by Oracle client libraries or other async DB drivers. Optional for general DB use.                                                                        |
| `libaio-dev`               | Oracle / async DB drivers              | Development headers for compiling async DB drivers. Only needed at build time.                                                                                   |
| `libnsl`                   | Legacy / older precompiled DB binaries | Needed only if a precompiled driver complains about `libnsl.so.1`. Rarely required.                                                                              |
| `gcompat` / `libc6-compat` | Any (compatibility)                    | Not DB-specific, but sometimes needed for precompiled database drivers. Usually unnecessary if glibc is installed.                                               |
